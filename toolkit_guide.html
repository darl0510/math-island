💾 2. 智慧備份規則客製 (`backup_config.json`)

依照專案使用的程式語言（Python / Node.js / React / Vue / C# / PHP），自訂副檔名白名單與大型建置目錄排除：

backup_config.json 範例 JSON 
{
  "include_extensions": [
    ".py", ".json", ".html", 
    ".js", ".ts", ".css", ".sql"
  ],
  "exclude_dirs": [
    "node_modules", "dist", 
    "venv", ".git", "__pycache__"
  ],
  "max_single_file_mb": 20
}

💾 三層智慧備份與資料庫安全防線（極速・輕量・零遺漏） 3 層備份防禦
Layer 1: 輕量日常快照

auto_backup.smart_backup()

每次功能迭代完成時觸發，耗時 < 0.2 秒。僅備份核心業務代碼與配置，自動排除巨型 GeoJSON、node_modules 與快取檔。

Layer 2: 獨立資料持久化備份

auto_backup.backup_data_only()

專門備份 SQLite WAL 嵌入式資料庫（parking_storage.db）與各項 JSON 資料庫單檔，保障營運大數據永不丟失。

Layer 3: 跨主版號全量備份

auto_backup.full_archive()

當跨越重大主版號或每週五下班時封存，包含全量靜態資產與歷史檔案，作為冷儲存長期保存終極防禦。
